# Sharp Elevator & Escalator

Modern luxury web application for **Sharp Elevator & Escalator** — Kerala's trusted partner in vertical transportation, installation, maintenance, and modernisation.

## Features
- **Modern Responsive Design**: Engineered with a sleek black & gold luxury architectural design system.
- **Interactive Journey & Expertise Roadmap**: Smooth scroll-driven animated snake-path schematic with moving brand guide tracker across desktop, tablet, and mobile devices.
- **Dedicated Services Page**: Complete breakdown of Installation, Maintenance, Modernisation, and Specialised Solutions with 3×3 Polygon Mosaic Reveal animations.
- **Dedicated About Us Page**: Who We Are, Our Mission, Our Vision, and Our Commitment with Dual-Curtain Aperture Reveal animations.
- **Continuous Moving Announcements Strip**: Live ticker bar highlighting Kerala HQ, 24/7 hotline, AMC openings, and BIS/EN-81 safety certifications.
- **Zero-Error Codebase**: Built with React, Vite, Framer Motion, Lucide icons, and zero-error Oxlint validations.

## Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Vanilla CSS custom architecture with modern CSS variables
- **Animations**: Framer Motion & custom CSS GPU-accelerated keyframes
- **Icons**: Lucide React
